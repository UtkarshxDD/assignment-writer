🚀 Assignment Express - AI Feature Demo

✨ New AI-Powered Features

Assignment Express now includes cutting-edge AI capabilities powered by Google's Gemini API!

🎯 What's New:

  • AI Assignment Generation: Automatically create essays, reports, summaries, and more
  • Multi-Page Support: Large assignments automatically split across multiple pages
  • Interactive Navigation: Slide through pages with previous/next controls
  • Smart Formatting: Proper academic structure with introduction, body, and conclusion
  • Page Management: Add, delete, and organize pages with ease

Step 1: Get Your Gemini API Key

Visit Google AI Studio to get your free Gemini API key.

1. Go to Google AI Studio
2. Sign in with your Google account
3. Create API Key → Create API key in new project
4. Copy your API key

Step 2: Generate Your First Assignment

Open the Assignment Express application and follow these steps:

  1. Enter your Gemini API key in the "AI Assignment Generator" section
  2. Type your assignment topic (e.g., "Climate Change Effects")
  3. Select assignment type (Essay, Report, Summary, Analysis, Research Paper)
  4. Choose word count (250-1500 words)
  5. Click "Generate Assignment" 🪄

Step 3: Navigate Multiple Pages

For longer assignments, pages are automatically created:

  • Use Previous/Next buttons to navigate
  • View page indicator (e.g., "Page 1 of 3")
  • Each page maintains its own formatting settings
  • Add or delete pages as needed

Step 4: Customize and Download

Perfect your assignment with these options:

  • Adjust X/Y position, font size, and line spacing for each page
  • Upload custom backgrounds and fonts
  • Download individual pages or all pages at once
  • Toggle dark mode for better viewing
